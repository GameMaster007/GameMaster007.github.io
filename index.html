EV-001Lead dev · personal

Auto Forensics Framework

AI drafts, the analyst verifies, everything is cited. A triage tool that keeps a finding only when it points at real evidence.

pythonollamasha-256 citationsdfir
Examine evidence
  • Drafts findings with open-source LLMs via Ollama, and drops any finding that doesn't cite a hashed artifact: file, row or byte offset, and SHA-256.
  • Every run writes a manifest of input hashes, tool calls and the report hash, so it can be replayed and re-verified.
  • Treats evidence as untrusted data fenced off from model instructions, and imports Plaso, Hayabusa and Chainsaw exports.
  • Fine-tuning a domain model is on the roadmap.
